# 🚗 SmartPark

A futuristic smart parking management system built using **Flask**, **MySQL**, **HTML**, **CSS**, and **JavaScript**.

## ✨ Features

- Real-time parking slot status
- Manual slot selection
- Vehicle entry & exit management
- Automatic slot occupancy updates
- Parking records/history tracking
- Modern cyberpunk-inspired UI
- MySQL trigger-based automation

---

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- Vanilla JavaScript

### Backend
- Python Flask
- MySQL

## ⚙️ Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Sahil4507/smartpark.git
cd smartpark
```

### 2️⃣ Install dependencies

```bash
pip install flask mysql-connector-python
```

### 3️⃣ Setup MySQL Database

Create a database named:

```sql
CREATE DATABASE smartpark;
```

Update your MySQL credentials inside `app.py`.

---

## ▶️ Run the Project

```bash
python app.py
```

Open in browser:

```bash
http://127.0.0.1:5000
```
